# Dependency and data licences (checked 2026-10-22)

The project is Apache-2.0, so nothing GPL may be merged, and data whose terms
are unclear is fetched by script rather than committed.

| Item | Used for | Licence | Status |
|---|---|---|---|
| [DDS 2.9.0](https://github.com/dds-bridge/dds/tree/v2.9.0) | double-dummy solver, loaded at run time | Apache-2.0 | OK. Every source file is by Bo Haglund / Soren Hein; no bundled third-party code. Not committed; `scripts/build_dds.sh` builds it with two local patches. |
| `bridge_ai.dds` binding | our ctypes wrapper | Apache-2.0 (ours) | OK. No third-party binding at run time. |
| [endplay](https://github.com/dominicprice/endplay) | reference DDS build in `scripts/verify_dds.py` only | MIT | OK. Optional `verify` extra, not a run-time dependency. |
| [brl](https://github.com/harukaki/brl) code | bidding training (fork) | Apache-2.0 | OK. Keep its LICENSE and add a NOTICE entry in the fork. |
| brl model weights (`bridge_models/*.pkl`) | starting point for M2 | Apache-2.0 | OK to use and redistribute. They sit in the repo under its Apache-2.0 LICENSE and the README says "License: Apache 2.0" with no exception for the models. They were trained on WBridge5-generated data (see the OpenSpiel row); we keep attribution and do not claim WBridge5 endorsement. |
| [bridge_env](https://github.com/yotaroy/bridge_env) | brl's Table Manager client for WBridge5 matches | MIT | OK. Keep its copyright notice if vendored. |
| [Pgx 1.4.0](https://github.com/sotetsuk/pgx) | bidding environment | Apache-2.0 (the MinAtar extension is GPL-3.0; we do not use it) | OK. |
| Pgx DDS dataset ([Hugging Face](https://huggingface.co/datasets/sotetsuk/dds_dataset)) | RL rewards | not yet read (Hugging Face is blocked from the build container) | Open. `scripts/fetch_dds_data.sh` prints the dataset card on download; until then, download only, never commit. |
| [OpenSpiel WBridge5 bidding data](https://storage.googleapis.com/openspiel-data/bridge/README.txt) | supervised pre-training | no licence stated; generated by WBridge5 (closed source, Yves Costel) | Open. Download script only, never redistribute. Not needed if we start from brl's `model-sl.pkl`. |
| WBridge5 | evaluation opponent | freeware, closed source | Run only; never redistribute. |
| [BEN](https://github.com/lorserker/ben) | evaluation opponent, ideas | GPL-3.0 | Never merge code; run as a separate process only. |
